### 数据表结构

#### 1. users（用户表）
```sql
- id: 主键
- username: 用户名（唯一）
- email: 邮箱（唯一）
- password: 加密密码
- first_name: 名字
- last_name: 姓氏
- avatar: 头像URL
- bio: 个人简介
- role: 角色（user/moderator/admin）
- is_active: 是否启用
- is_email_verified: 邮箱是否验证
- learning_progress: 学习进度（JSON）
- preferences: 偏好设置（JSON）
- created_at: 创建时间
- updated_at: 更新时间
```

#### 2. posts（帖子表）
```sql
- id: 主键
- author_id: 作者ID（外键）
- title: 标题
- content: 内容
- category: 分类
- hashtags: 标签（JSON）
- images: 图片（JSON）
- videos: 视频（JSON）
- likes_count: 点赞数
- views: 浏览量
- is_deleted: 是否删除
- created_at: 创建时间
```

#### 3. comments（评论表）
```sql
- id: 主键
- post_id: 帖子ID（外键）
- user_id: 用户ID（外键）
- content: 内容
- parent_id: 父评论ID（支持回复）
- likes_count: 点赞数
- is_deleted: 是否删除
- created_at: 创建时间
```

#### 4. learning_records（学习记录表）
```sql
- id: 主键
- user_id: 用户ID（外键）
- lesson_type: 课程类型
- lesson_id: 课程ID
- lesson_name: 课程名称
- completed: 是否完成
- score: 分数
- time_spent: 学习时长（分钟）
- completed_at: 完成时间
- created_at: 创建时间
```

#### 5. translation_records（翻译记录表）
```sql
- id: 主键
- user_id: 用户ID（外键）
- input_type: 输入类型（image/video/camera）
- input_content: 输入内容
- result: 翻译结果
- confidence: 置信度
- model_used: 使用的模型
- processing_time: 处理时间
- created_at: 创建时间
```

#### 6. likes（点赞表）
```sql
- id: 主键
- user_id: 用户ID（外键）
- target_type: 目标类型（post/comment）
- target_id: 目标ID
- created_at: 创建时间
```

#### 7. admin_logs（管理员操作日志表）
```sql
- id: 主键
- admin_id: 管理员ID（外键）
- action: 操作类型
- target_type: 目标类型
- target_id: 目标ID
- details: 详情（JSON）
- ip_address: IP地址
- created_at: 创建时间
```

## 🔧 后端API端点

### 认证相关
- `POST /api/auth/register` - 用户注册
- `POST /api/auth/login` - 用户登录
- `POST /api/auth/logout` - 用户登出
- `GET /api/auth/me` - 获取当前用户信息
- `PUT /api/auth/profile` - 更新个人信息
- `PUT /api/auth/change-password` - 修改密码

### 用户相关
- `GET /api/users/learning-progress` - 获取学习进度
- `POST /api/users/learning-progress` - 更新学习记录
- `GET /api/users/translation-history` - 获取翻译历史

### 社区相关
- `GET /api/community/posts` - 获取帖子列表
- `GET /api/community/posts/:id` - 获取帖子详情
- `POST /api/community/posts` - 创建帖子
- `POST /api/community/posts/:id/comments` - 添加评论
- `POST /api/community/posts/:id/like` - 点赞/取消点赞

### 学习相关
- `GET /api/learning/courses` - 获取课程列表
- `GET /api/learning/stats` - 获取学习统计

### 翻译相关
- `POST /api/translation/record` - 保存翻译记录
- `GET /api/translation/records` - 获取翻译记录

### 管理员相关（需要管理员权限）
- `GET /api/admin/stats` - 系统统计
- `GET /api/admin/users` - 用户列表
- `GET /api/admin/users/:id` - 用户详情
- `PATCH /api/admin/users/:id/role` - 修改用户角色
- `PATCH /api/admin/users/:id/status` - 启用/禁用用户
- `DELETE /api/admin/users/:id` - 删除用户
- `GET /api/admin/posts` - 帖子列表
- `DELETE /api/admin/posts/:id` - 删除帖子
- `GET /api/admin/comments` - 评论列表
- `DELETE /api/admin/comments/:id` - 删除评论
- `GET /api/admin/logs` - 操作日志

## 🔐 权限系统

### 角色定义
1. **普通用户（user）**
   - 访问首页、学习、翻译、社区
   - 发布帖子和评论
   - 查看个人学习进度

2. **版主（moderator）**
   - 普通用户所有权限
   - 管理社区内容（删除帖子/评论）

3. **管理员（admin）**
   - 所有权限
   - 访问管理后台
   - 用户管理
   - 查看系统统计
   - 查看操作日志

## 📝 注意事项

1. **数据库连接**
   - 确保MySQL服务已启动
   - 检查数据库配置是否正确

2. **首次运行**
   - 运行数据库初始化脚本：
   ```bash
   cd backend
   node scripts/init_mysql_database.js
   ```

3. **移动端摄像头**
   - 移动端访问需要HTTPS
   - 开发环境可使用ngrok或localtunnel

4. **测试账号**
   - 使用提供的测试账号进行功能测试
   - 管理员账号可访问所有功能

## 🐛 常见问题

### 1. 数据库连接失败
- 检查MySQL服务是否运行
- 检查用户名密码是否正确
- 检查数据库是否存在

### 2. 登录失败
- 确认后端服务已启动
- 检查网络连接
- 验证账号密码是否正确

### 3. 权限不足
- 确认用户角色是否正确
- 管理员功能需要admin角色

## 🔄 回滚方案

如需回滚到MongoDB版本：
1. 恢复 `backend/src/app.js` 为MongoDB版本
2. 恢复路由文件为MongoDB版本
3. 重启后端服务
