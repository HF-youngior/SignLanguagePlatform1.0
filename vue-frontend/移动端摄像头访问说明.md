# 移动端摄像头访问说明

## 重要提示

**移动端浏览器要求HTTPS才能访问摄像头！**

## 开发环境解决方案

### 方案1：使用本地HTTPS（推荐）

1. **安装mkcert**（生成自签名证书）
   ```bash
   # Windows (使用Chocolatey)
   choco install mkcert

   # macOS (使用Homebrew)
   brew install mkcert

   # Linux
   sudo apt install mkcert
   ```

2. **生成证书**
   ```bash
   # 安装CA证书到系统
   mkcert -install

   # 为本地开发生成证书
   mkcert localhost 127.0.0.1 ::1
   ```

3. **更新vite.config.js**
   ```javascript
   import fs from 'fs'
   import path from 'path'

   export default defineConfig({
     server: {
       port: 3000,
       host: '0.0.0.0',
       https: {
         key: fs.readFileSync(path.resolve(__dirname, 'localhost-key.pem')),
         cert: fs.readFileSync(path.resolve(__dirname, 'localhost.pem'))
       }
     }
   })
   ```

### 方案2：使用ngrok（快速测试）

1. **安装ngrok**
   ```bash
   # 下载ngrok: https://ngrok.com/download
   # 解压并添加到PATH
   ```

2. **启动ngrok**
   ```bash
   ngrok http 3000
   ```

3. **使用HTTPS URL**
   - ngrok会提供一个HTTPS URL，例如：`https://xxxx-xx-xx-xx-xx.ngrok.io`
   - 在手机浏览器中访问这个URL

### 方案3：使用localhost隧道（简单）

1. **安装localtunnel**
   ```bash
   npm install -g localtunnel
   ```

2. **启动隧道**
   ```bash
   lt --port 3000
   ```

3. **使用HTTPS URL**
   - localtunnel会提供一个HTTPS URL
   - 在手机浏览器中访问

## 摄像头权限处理

### 用户授权流程
1. 首次访问时，浏览器会请求摄像头权限
2. 用户需要点击"允许"
3. 如果拒绝，需要手动在浏览器设置中授权

### 常见错误及解决方案

#### 1. NotAllowedError
**错误信息**: 用户拒绝了摄像头权限
**解决方案**: 
- 在浏览器设置中允许摄像头权限
- 清除浏览器缓存和Cookie
- 重新访问网站

#### 2. NotFoundError
**错误信息**: 未找到摄像头设备
**解决方案**:
- 确认设备有摄像头
- 检查其他应用是否占用了摄像头
- 重启设备

#### 3. NotReadableError
**错误信息**: 摄像头可能被其他应用占用
**解决方案**:
- 关闭其他使用摄像头的应用
- 重启浏览器
- 重启设备

#### 4. OverconstrainedError
**错误信息**: 摄像头不支持请求的分辨率
**解决方案**:
- 降低请求的分辨率
- 使用默认分辨率
- 代码中已处理此错误

## 常见问题

### Q: 为什么手机上无法访问摄像头？
A: 移动端浏览器要求HTTPS才能访问摄像头，请使用上述方案之一配置HTTPS。

### Q: 开发环境必须使用HTTPS吗？
A: 是的，移动端浏览器强制要求HTTPS才能访问摄像头。桌面浏览器在localhost上可以使用HTTP。

### Q: 生产环境如何配置HTTPS？
A: 使用Let's Encrypt免费证书，或购买商业SSL证书，配置在Web服务器上。

### Q: 微信内置浏览器能用吗？
A: 微信内置浏览器对摄像头访问有限制，建议使用系统浏览器（Chrome、Safari等）。
