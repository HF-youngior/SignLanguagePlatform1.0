# 欢迎页面使用说明

## 📋 概述

这是一个独立的欢迎/登录页面，位于 `vue-frontend/src/views/Welcome.vue`。该页面在用户访问网站时首先显示，提供手部交互体验。

## ✨ 功能特性

1. **手部识别**：使用 MediaPipe 识别手部位置
2. **光标跟随**：手部移动时，画布上的光标会跟随移动
3. **花苞放置**：握拳时在当前位置放置花苞
4. **花朵绽放**：手张开时，花苞绽放成鲜花
5. **循环交互**：可以重复放置多个花苞和花朵
6. **点击进入**：点击画布进入主平台

## 🎨 设计特点

- **浅蓝色画布**：背景色为 `#B0E0E6`
- **动态光标**：带脉冲效果的光标跟随手部
- **花朵动画**：花苞到花朵的平滑绽放动画
- **响应式设计**：适配桌面和移动设备

## 🔧 技术实现

### MediaPipe 集成

页面使用 MediaPipe Hands 进行手部识别：
- 通过 CDN 动态加载 MediaPipe 库
- 如果 MediaPipe 加载失败，自动切换到模拟模式（鼠标控制）

### 模拟模式

当以下情况发生时，会自动切换到模拟模式：
- MediaPipe CDN 无法加载
- 摄像头无法访问
- 浏览器不支持 MediaPipe

在模拟模式下：
- 鼠标移动控制光标
- 鼠标按下创建花苞
- 鼠标释放让花苞绽放

## 🚀 使用方法

### 1. 启动开发服务器

```bash
cd vue-frontend
npm run dev
```

### 2. 访问页面

打开浏览器访问：`http://localhost:3000`

现在会首先显示欢迎页面，而不是原来的首页。

### 3. 交互方式

**使用摄像头（推荐）**：
1. 允许浏览器访问摄像头
2. 将手放在摄像头前
3. 移动手，光标会跟随
4. 握拳放置花苞
5. 张开手让花苞绽放
6. 点击画布进入平台

**使用鼠标（模拟模式）**：
1. 移动鼠标，光标会跟随
2. 按下鼠标创建花苞
3. 释放鼠标让花苞绽放
4. 点击画布进入平台

## ⚙️ 配置说明

### MediaPipe CDN

如果 MediaPipe CDN 无法访问，可以：

1. **使用本地文件**：
   - 下载 MediaPipe 文件到 `public` 目录
   - 修改 `Welcome.vue` 中的 `locateFile` 函数

2. **使用其他 CDN**：
   - 修改脚本加载地址
   - 例如：`https://unpkg.com/@mediapipe/hands/hands.js`

### 摄像头设置

摄像头配置在 `onMounted` 中：
```javascript
const stream = await navigator.mediaDevices.getUserMedia({ 
  video: { 
    width: 1280, 
    height: 720,
    facingMode: 'user'  // 前置摄像头
  } 
})
```

## 🐛 故障排查

### 问题1：摄像头无法访问

**解决方案**：
- 检查浏览器权限设置
- 确保使用 HTTPS 或 localhost
- 检查是否有其他应用占用摄像头

### 问题2：MediaPipe 无法加载

**解决方案**：
- 检查网络连接
- 尝试使用 VPN（如果CDN被屏蔽）
- 系统会自动切换到模拟模式

### 问题3：手部识别不准确

**解决方案**：
- 确保光线充足
- 手部与摄像头保持适当距离（30-80cm）
- 背景简洁，避免复杂背景

### 问题4：页面无法进入主平台

**解决方案**：
- 检查路由配置是否正确
- 确保 `/home` 路由存在
- 查看浏览器控制台错误信息

## 🎯 自定义选项

### 修改画布颜色

在 `Welcome.vue` 的 `drawCanvas` 函数中：
```javascript
ctx.fillStyle = '#B0E0E6' // 修改这里的颜色
```

### 修改花朵样式

在 `drawFlower` 和 `drawBud` 函数中调整：
- 花瓣数量：`petals: 5 + Math.floor(Math.random() * 4)`
- 花朵大小：`maxSize: 30 + Math.random() * 20`
- 花朵颜色：`color: hsl(...)`

### 修改动画速度

在 `bloomLastBud` 函数中：
```javascript
flower.bloomProgress = Math.min(elapsed / 1000, 1) // 1000 = 1秒，可调整
```
